Entry for the make.fun bounty
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) ($2).

`main.py` writes one original fortune-cookie line for a software
developer to `/output/entry.txt`:

> The legacy code you curse was written by someone who, like you, was only trying to ship by Friday.

Run with `python3 main.py`.
